你好，欢迎使用 pLedger 思源账本, 一个基于思源笔记的账本插件

## 用前必读

### 插件配置

- 【**图标配置**】用于自定义图标，后续可以用 icon name 在资产/记账部分的配置中引用，图标名称必须是唯一的，格式必须为 siyun 可以解析的 svg 格式，例如：
  ```xml
  <symbol id="iconD3TestIcon" viewBox="0 0 1024 1024">
  <path d="M648.53333333 921.6a34.13333333 34.13333333 0 0 1-32.08533333-23.21066667L375.46666667 176.128 271.01866667 488.78933333A34.13333333 34.13333333 0 0 1 238.93333333 512H34.13333333a34.13333333 34.13333333 0 0 1 0-68.26666667h180.224l129.024-386.38933333a35.49866667 35.49866667 0 0 1 64.85333334 0L648.53333333 779.60533333l104.448-312.66133333A34.13333333 34.13333333 0 0 1 785.06666667 443.73333333h204.8a34.13333333 34.13333333 0 0 1 0 68.26666667h-180.224l-129.024 386.38933333A34.13333333 34.13333333 0 0 1 648.53333333 921.6z"></path>
  </symbol>
  ```
- 【**资产配置**】
  - 【**数据存放位置**】必须为文档ID，不能是笔记本ID，插件会在你配置的【数据存放位置】文档下按年创建新的子文档，用于存储资产数据
  - 【**目标金额**】为资产的目标金额，默认值为 100w
  * 【**配置**】中推荐配置的数据必须只能是两层，目前插件不支持多层级的复杂配置，其中 icon 可以是自定义图标名称，也可以是 emoji 表情，例如 "💵"，例如：
  ```json
  [{
    "name": "测试",
    "icon": "iconD3TestIcon", // or "💵"
    "children": [
      { "name": "测试1" },
      { "name": "测试2" }
    ]
  }]
  ```
- 【**记账配置**】
  - 【**数据存放位置**】会根据【存放方式】不同而不同：
    - 选择【集中存放】时必须填写文档ID，插件会在该文档下按 `yyyy-MM` 创建月份子文档，用于存储记账数据
    - 选择【按日期存放】时必须填写笔记本ID，插件会读取该笔记本的【新建日记路径】配置，并按日期写入对应的日记文档
  - 【**存放方式**】目前支持两种：
    - 【集中存放】适合把记账数据统一放在一个文档目录下管理
    - 【按日期存放】适合把记账数据跟随思源日记一起保存，如果当天日记不存在，插件会尝试按日记路径创建文档
  - 【**每月预算**】用于记账统计中的预算计算，默认值为 3000
  * 【**标签配置**】中推荐配置的数据必须只能是两层，目前插件不支持多层级的复杂配置
    其中 icon 可以是自定义图标名称，也可以是 emoji 表情，例如 "🍔"，例如：
  ```json
  [{
    "name": "餐饮",
    "icon": "🍔",
    "children": [
      { "name": "早餐" },
      { "name": "午餐" },
      { "name": "晚餐" },
      { "name": "零食" },
      { "name": "其他" }
    ]
  }]
  ```

### 注意事项

- **任何配置均不要频繁变更，变更前建议切换【数据存放位置】或备份原始数据，数据丢失是不可逆的**
- **你在文档中的修改会影响插件，如果你不知道你在做什么，请不要在文档中直接修改资产数据，尤其是【记账】相关内容，插件目前是按照块属性进行检索的，仅改文档内容可能会产生脏数据**
- **如果你的数据出现问题，请使用数据维护功能进行修复，该功能会扫描所有包含 \`**`custom-pledge`**\` 的块，以下是可能的问题：**

| 异常原因                              | 可能出现的原因                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------- |
| `custom-pledge 不是有效的 JSON 对象`     | 属性被手动修改、内容被截断、JSON 引号或括号不完整，或者属性值不是对象。                                                            |
| `属性所在块不存在或无法读取所属文档`               | 属性记录仍存在，但对应块已被删除；数据库索引尚未同步；块无法查询到实际文档 ID。                                                         |
| `块所属文档不存在或位置无法访问`                 | 文档已删除、笔记本关闭或不存在、文档迁移后路径失效，或者无法读取块的实际路径。                                                           |
| `缺少日期、类型、分类或有效金额等业务字段`            | 缺少 `date`、`type`、`parentName`、`childName`、`amount`；日期格式错误；类型不是 `income/expense`；金额无法转换为数字。        |
| `属性字段缺失或格式异常：字段名`                 | 属性缺少标准字段；字段值类型错误；例如缺少 `storageRootId`、`documentId`、`blockId`、`month`，或者金额、备注格式不正确。                |
| `属性与实际位置或当前配置冲突：字段名`              | 属性中的 `storageMode`、`storageRootId`、`documentId`、`blockId` 与当前配置或块的实际位置不一致，常见于文档迁移、切换存放方式或更换存放位置后。 |
| `包含无用属性：字段名`                      | 旧代码将页面临时字段写入属性，例如 `id`、`icon`；也可能是历史版本遗留字段或用户手动增加的字段。                                             |
| `属性声明属于当前配置，但块的实际位置已经越界`          | `storageMode` 和 `storageRootId` 仍指向当前配置，但块被手动移动到了配置范围之外，或迁移时只移动了块而没有更新属性。                         |
| `可以识别存放方式或历史根位置，但不属于当前配置`         | 数据属于旧配置、旧笔记本或旧集中存放文档；切换配置后原数据仍保留；也可能是其他记账配置的数据。                                                   |
| `storageMode 缺失或无效，且无法根据当前位置可靠推断` | 历史数据没有 `storageMode`；值不是 `central/date`；块的位置也不足以判断其原存放方式。                                         |
| `不属于当前配置，且无法可靠识别其目标配置`            | 数据实际位置在当前配置之外，同时缺少有效的存放方式或根位置，无法确定应该归入哪个配置。                                                       |

- **属性`custom-pledge`** **标准**

| 字段              | 必填 | 标准格式                     | 说明                                 |
| --------------- | -: | ------------------------ | ---------------------------------- |
| `type`          |  是 | `"income"` 或 `"expense"` | 收入或支出                              |
| `date`          |  是 | `YYYY-MM-DD`             | 记账日期，例如 `2026-08-11`               |
| `parentName`    |  是 | 非空字符串                    | 一级分类，必须与当前记账配置一致                   |
| `childName`     |  是 | 非空字符串                    | 二级分类，必须属于对应的一级分类                   |
| `amount`        |  是 | 大于 0 的数字                 | 金额，必须是数字，不能是字符串，例如 `4`，不能写成 `"4"`  |
| `remark`        |  是 | 字符串                      | 备注，可以是空字符串 `""`                    |
| `month`         |  是 | `YYYY-MM`                | 必须与 `date` 的年月一致                   |
| `storageMode`   |  是 | `"central"` 或 `"date"`   | 分别表示集中存放、按日期存放                     |
| `storageRootId` |  是 | 非空字符串                    | 数据所属配置的根文档 ID 或笔记本 ID              |
| `documentId`    |  是 | 有效文档 ID                  | 必须是块实际所属文档的 ID                     |
| `blockId`       |  是 | 有效块 ID                   | 必须与承载该属性的实际块 ID 一致                 |
| `createdAt`     |  否 | ISO 日期时间字符串              | 创建时间，例如 `2026-08-11T08:30:00.000Z` |
| `displayTime`   |  否 | `HH:mm`                  | 时间，例如 `08:30`                      |

你好，欢迎使用 pLedger 思源账本, 一个基于思源笔记的账本插件

## 用前必读

### 插件配置

- 【**图标配置**】用于自定义图标，后续可以用 icon name 在资产/记账部分的配置中引用，图标名称必须是唯一的，格式必须为 siyun 可以解析的 svg 格式，例如：
  ```xml
  <symbol id="iconD3TestIcon" viewBox="0 0 1024 1024">
  <path d="M648.53333333 921.6a34.13333333 34.13333333 0 0 1-32.08533333-23.21066667L375.46666667 176.128 271.01866667 488.78933333A34.13333333 34.13333333 0 0 1 238.93333333 512H34.13333333a34.13333333 34.13333333 0 0 1 0-68.26666667h180.224l129.024-386.38933333a35.49866667 35.49866667 0 0 1 64.85333334 0L648.53333333 779.60533333l104.448-312.66133333A34.13333333 34.13333333 0 0 1 785.06666667 443.73333333h204.8a34.13333333 34.13333333 0 0 1 0 68.26666667h-180.224l-129.024 386.38933333A34.13333333 34.13333333 0 0 1 648.53333333 921.6z"></path>
  </symbol>
  ```
- 【**资产配置**】
  - 【**数据存放位置**】必须为文档ID，不能是笔记本ID，插件会在你配置的【数据存放位置】文档下按年创建新的子文档，用于存储资产数据
  - 【**目标金额**】为资产的目标金额，默认值为 100w
  * 【**配置**】中推荐配置的数据必须只能是两层，目前插件不支持多层级的复杂配置，其中 icon 可以是自定义图标名称，也可以是 emoji 表情，例如 "💵"，例如：
  ```json
  [{
    "name": "测试",
    "icon": "iconD3TestIcon", // or "💵"
    "children": [
      { "name": "测试1" },
      { "name": "测试2" }
    ]
  }]
  ```
- 【**记账配置**】
  - 【**数据存放位置**】会根据【存放方式】不同而不同：
    - 选择【集中存放】时必须填写文档ID，插件会在该文档下按 `yyyy-MM` 创建月份子文档，用于存储记账数据
    - 选择【按日期存放】时必须填写笔记本ID，插件会读取该笔记本的【新建日记路径】配置，并按日期写入对应的日记文档
  - 【**存放方式**】目前支持两种：
    - 【集中存放】适合把记账数据统一放在一个文档目录下管理
    - 【按日期存放】适合把记账数据跟随思源日记一起保存，如果当天日记不存在，插件会尝试按日记路径创建文档
  - 【**每月预算**】用于记账统计中的预算计算，默认值为 3000
  * 【**标签配置**】中推荐配置的数据必须只能是两层，目前插件不支持多层级的复杂配置
    其中 icon 可以是自定义图标名称，也可以是 emoji 表情，例如 "🍔"，例如：
  ```json
  [{
    "name": "餐饮",
    "icon": "🍔",
    "children": [
      { "name": "早餐" },
      { "name": "午餐" },
      { "name": "晚餐" },
      { "name": "零食" },
      { "name": "其他" }
    ]
  }]
  ```

### 注意事项

- **任何配置均不要频繁变更，变更前建议切换【数据存放位置】或备份原始数据，数据丢失是不可逆的**
- **你在文档中的修改会影响插件，如果你不知道你在做什么，请不要在文档中直接修改资产数据，尤其是【记账】相关内容，插件目前是按照块属性进行检索的，仅改文档内容可能会产生脏数据**
